# Labyrinth Foundation

Labyrinth Foundation Inc. is a 501(c)(3) public charity creating free educational and creative games, interactive experiences, and digital projects for learning through play.

**Website:** https://labyrinthfoundation.org  
**Games:** https://labyrinthfoundation.org/games  
**EIN:** 39-3464420

## What we do

We create free games and interactive projects that explore creativity, experimentation, problem solving, and learning through play.

GitHub is where we develop the software behind those nonprofit programs, maintain the technology that makes them available, and publish resources that can be useful beyond our own projects.

### Inclusive Game Design

[Inclusive Game Design](https://github.com/Labyrinth-Foundation/inclusive-game-design) is an open Labyrinth Foundation initiative for making games and interactive experiences easier for more people to play.

The project publishes practical design guidance, testing methods, checklists, and reference examples drawn from lessons we encounter while building and testing our own work. Initial topics include reduced motion, keyboard and controller input, accessible touch interactions, and practical accessibility testing.

The resource is openly licensed and welcomes contributions from players, developers, designers, researchers, educators, accessibility practitioners, and people who use assistive technologies.

**Explore the project:** https://github.com/Labyrinth-Foundation/inclusive-game-design

### Games and interactive experiences

Our growing collection of free games and interactive experiences is available at https://labyrinthfoundation.org/games.

We casually refer to this collection as **Labyrinth Arcade**. A larger Labyrinth Arcade project is still in development and is not yet published.

Most of our production repositories remain private while projects are actively developed. We selectively publish projects and reusable resources when they are ready to be useful to the broader community.
